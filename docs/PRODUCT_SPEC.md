# 产品规格

## 愿景

OpenLearnGraph 将任何学习目标转化为持续演化的知识地图，由未来的 Tutor Agent 根据知识结构、学习者状态、证据与历史决定下一步学习行动。

核心循环：学习目标 → 知识图谱 → 学习者状态 → TutorDecision → 教学/评估/练习/复习 → Evidence → 状态更新 → 重规划。

## 当前范围：M0–M7B

- Windows 本地 Electron 应用；React Flow 是主工作区。
- 全新空白资料库首次启动时展示可跳过的欢迎入口，可选择导入资料、手工建图或创建可删除示例；迁移时已经存在图谱的用户默认不被强制打断。
- 提供可关闭、可继续、可主动结束且可从侧栏重新打开的六项任务式指南。任务完成度只表示是否走通过功能，不参与 learner state 或知识掌握进度计算。
- 内置示例由本地事务创建，包含概念描述、先修关系及手工预置的练习/诊断通用题，不调用 AI；界面持续标记其示例身份，并只允许通过专用确认操作删除该示例及其级联数据。
- 创建、命名和加载多个知识图谱。
- 创建、选择、编辑、拖动、删除概念节点。
- 创建和删除有向 `PREREQUISITE` 关系。
- 保存图名、节点、边与节点位置到 SQLite，重启后恢复。
- 拒绝空白名称、自循环边、重复边与悬空边。
- 拒绝会形成循环学习路径的先修关系。
- 为概念记录“开始学习”和 1–5 分自评证据，可附学习备注。
- 根据证据与先修结构投影 `LOCKED / AVAILABLE / LEARNING / MASTERED`，并展示状态原因。
- 为每个概念创建、编辑和删除 2–6 个选项的单选题，指定唯一正确答案、可选解析，以及 `DIAGNOSTIC / PRACTICE / BOTH` 用途。
- 仅让题目数达到 2 道的概念参与图谱诊断，允许学习者明确回答“我不知道”。
- 按概念生成不可变题目快照、作答记录和客观诊断 Evidence；正确率达到 80% 才投影为 `MASTERED`。
- 提交后展示按概念汇总与逐题回顾；退出未提交的诊断不会生成学习证据。
- 支持显式选择本次诊断范围、快捷选择最近诊断未掌握的概念，并只更新所测概念的客观结论。
- 每次选择即时保存；应用重启后恢复答案并定位到第一道未答题，用户也可主动放弃为取消记录。
- 展示最近 100 次诊断历史，可重新打开已完成结果并针对未掌握概念发起重测。
- 最近一次客观诊断是决定状态的证据，之后的主观自评只进入时间线，不覆盖客观结论。
- 证据、学习状态和图谱结构均保存在本机，重启后恢复。
- 在当前图谱与图谱列表展示可持续追踪的学习进度；总进度仅统计 Evidence 投影为 `MASTERED` 的概念，并把客观诊断确认与主观自评掌握分别列出。
- 单独展示 `LEARNING / AVAILABLE / LOCKED` 状态分布和诊断题库准备度；导入、候选生成、题库覆盖、学习会话与形成性练习本身均不会增加掌握进度。
- 学习、练习和诊断完成页给出克制的成果反馈，说明本次证据的含义、状态变化、后续解锁及推荐下一步，不用积分或徽章替代真实学习结果。
- 根据当前图谱、学习状态、题库覆盖和未完成诊断生成一个确定性的下一步建议。
- 建议动作限制为 `TEACH / ASSESS / PRACTICE / REVIEW / REMEDIATE / ADVANCE`，并展示人类可读理由和事实依据。
- 记录建议的规则版本、目标、用户采纳/忽略响应与失效状态；相同状态复用同一建议，状态变化后保留旧记录用于审计。
- 采纳建议只导航到目标执行入口；`TEACH / ADVANCE` 会打开学习会话，建议本身不产生 Evidence，也不直接改变 learner state。
- 为 `TEACH / ADVANCE` 提供本地三步学习会话：阅读已保存的概念描述、主动回忆、书面总结。
- 会话记录开始时的概念和先修状态快照，笔记与步骤自动保存；关闭应用后可继续唯一的活动会话。
- 完成会话才生成 `LEARNING_SESSION_COMPLETED` Evidence；主动取消只保留历史，不产生 Evidence。
- 学习会话不会自行宣称掌握；已有客观诊断结论不会被会话完成覆盖。
- 同一图谱不允许学习会话、形成性练习与诊断并行，避免多个活动流程产生含糊状态。
- 为 `PRACTICE / REMEDIATE / REVIEW` 提供逐题形成性练习：每次提交立即显示正确答案和解析，答案写入后不可修改。
- 练习开始时复制题目、选项和解析；实时题库之后的编辑或删除不会改变已有练习记录。
- 已作答反馈和当前位置可跨进程恢复，展示最近 100 次完成、取消和活动记录。
- 完成练习生成 `PRACTICE_RESULT` Evidence，记录正确率但不直接产生 `MASTERED`；取消不生成 Evidence。
- 最近一次客观诊断继续决定状态；补强练习完成后，Tutor 建议重新诊断，而不是以练习成绩替代诊断结论。
- 每个图谱最多有一个活动教学、练习或诊断流程，删除活动流程的目标概念会被前端和持久化层同时阻止。
- 通过系统文件选择器一次选择最多 20 份不超过 100 MB 的 PDF、EPUB、Markdown 和 TXT 资料；解析完全在主进程逐份执行，成功项进入逐本预览队列，单个失败不会阻止其他资料，也不调用 AI API 或网络服务。
- 在持久化前展示可编辑的书目信息、格式/编码/页数/章节数/字符数、提取警告和按章节或页码组织的文本预览。
- 以 SHA-256 识别内容完全相同的资料；确认导入前再次检查原文件的大小和修改时间，避免预览后文件被替换。
- 对常见纯文本编码进行识别和解码；PDF 保留逐页定位，EPUB 按书脊顺序保留章节。没有可提取文本层的扫描 PDF 会明确提示需要 OCR，不保存为空资料。
- 确认导入后把元数据和提取文本保存到本机 SQLite，原始文件路径不暴露给 renderer；资料可重新打开和删除。
- 从已导入正文的精确选区创建学习内容建议；底层候选记录保存资料名、章节/页码、字符区间和不可变原文快照。
- “学习路线预览”以用户语言展示目标图谱、准备加入的内容、先学/再学顺序、本地检查结果与可选的逐项核对进度；AI 关系同时展示具体原因和独立原文依据，用户可保留、修改、排除和恢复建议，也可返回原文章节定位。
- 用户不需要自行设计知识结构：AI 或手工选区负责提出建议，应用负责引用、重名、重复、循环和规模检查；用户负责排除明显不需要的内容、修正术语并作最终整体确认。
- 与正式图谱或候选集重名、引用非待审核候选、形成循环或超过规模限制时拒绝写入。
- 最终确认前展示准确的新增内容/顺序数量和不受影响的既有图谱规模；确认后才在单个事务中写入正式图谱，接受、忽略、可选逐项核对时间和来源快照作为审核历史保留。
- 配置 DeepSeek `deepseek-flash / deepseek-v4-pro`；API Key 只经密码输入控件和窄 IPC 交给 main，以 Electron `safeStorage` 调用 Windows 安全存储加密，不从 main 返回。
- 生成前先明确选择已有/新建的目标图谱，以及最多 80 个连续章节、合计不超过 256,000 字符的范围；再展示目标图谱、资料、章节、字符数、批次数和摘要，未勾选明确同意时不发送任何正文。
- 仅向 DeepSeek 发送用户确认的正文，按每批最多 32,000 字符自动拆分；不发送原始文件、本地路径、其他章节或学习状态，请求可取消，超时和服务错误均有明确反馈。
- 每批 DeepSeek JSON 经运行时 schema、唯一性、先修循环和出处编号校验；概念与关系的引用文字和位置都由 main 从本地原文重建。AI 关系必须说明目标如何直接使用先修概念，并提供独立出处；允许不生成关系，不为了连通图谱而补边。任一批失败时不留下部分候选。
- 通过校验的 AI 输出只以 `PENDING` 候选保存，标记模型来源；生成状态、发送范围、token 数和结果数量可审计，不记录密钥。

## 明确不在当前范围

自动出题、开放题评分、基于难度或能力参数的自适应选题、生成式教学内容、间隔复习调度、除 DeepSeek 外的 provider、DOCX 提取、本地 OCR、RAG、账号、云同步、遥测和自动更新均不在当前范围。AI 只能提出候选，不会自动修改正式图谱。题库由用户手工维护，客观结论只来自本地单选诊断；没有诊断结果时，4–5 分自评仍可形成主观的 `MASTERED` 状态。AI 候选不产生 Evidence，不改变 learner state。

## Tutor 决策约束

动作空间固定为 `TEACH | ASSESS | PRACTICE | REVIEW | REMEDIATE | ADVANCE`。当前 Tutor 是完全本地、确定性的规则决策，与 M7B 的 DeepSeek 候选生成相互独立。未来即使为 Tutor 接入 LLM，也只能产出经运行时验证的 `TutorDecision`，再由应用服务执行用户确认的导航或会话；LLM 不得直接修改数据库。只有真实学习/作答行为可以产生 Evidence，再由 learner model 更新状态。
